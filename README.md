# SAIRO — Cultural Fit Busan

외국인 대상 부산 문화 적합도 기반 관광 추천 웹 서비스

> 2026 관광데이터 활용 공모전 출품작

## 기술스택

- **프레임워크**: Next.js 16 (App Router)
- **스타일링**: Tailwind CSS v4
- **DB / Auth**: Supabase
- **외부 API**: 한국관광공사 TourAPI 4.0
- **배포**: Vercel

## 핵심 — CFP 16유형

4축 이분법(분위기 Q/V · 로컬 L/F · 음식 M/H · 이동 S/W)으로
여행자를 16가지 문화 성향 유형으로 분류하고, 맞춤 장소를 추천합니다.

## 로컬 개발

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인
