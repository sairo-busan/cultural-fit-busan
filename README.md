# SAIRO — Cultural Fit Busan

부산을 방문한 외국인 관광객이 현장에서 **지금 무엇을, 어떤 순서로** 하면 좋을지 안내받는 실시간 여행 가이드.

여행 전에 일정을 미리 짜는 방식이 아니라, 현재 위치·시간·날씨·운영 여부를 반영해 동선과 안내를 실시간으로 재구성합니다.

> 2026 관광데이터 활용 공모전 웹·앱 개발 부문 출품작

## 왜 만들었는가

기존 관광 정보 서비스는 장소 소개·운영시간·번역 수준에 머물러 있습니다. 관광객이 실질적으로 필요로 하는 **"이 장소가 지금 나에게 맞는가"**에 대한 판단 근거를 제공하지 못합니다.

- **계획형 서비스와 현장의 간극** — 비가 오거나, 장소가 문을 닫았거나, 예상보다 붐비는 상황에서 즉시 대안을 제시하는 서비스가 부족
- **개인 성향에 따라 필요한 정보가 다름** — 비건, 조용한 환경 선호, 현지 방식 체험 희망 등 같은 장소에 대해 전혀 다른 정보가 필요
- **부산은 사전 안내의 효과가 가장 큰 지역** — 활어회·포장마차·찜질방·전통시장 등 안내 한 번으로 체험 만족도가 크게 달라지는 자원이 밀집

## 핵심 — CFP 16유형 체계

4개 문항으로 **문화 적합도 프로필(Cultural Fit Profile)** 16유형 중 하나를 판정합니다.

```
분위기  Q(Quiet)   / V(Vibrant)
로컬    L(Local)   / F(Famous)
음식    M(Mild)    / H(Hot)
이동    S(Stroll)  / W(Wander)
```

한국관광공사 TourAPI로 수집한 부산 관광 콘텐츠에 자체 구축한 문화 적합도 메타데이터를 결합해, 유형별로 다른 순서와 안내를 제공합니다.

## 핵심 기능

| | 기능 | 한 줄 |
|---|---|---|
| F1 | 문화 적합도 프로필 진단 | 4문항 이분법으로 CFP 16유형 판정 |
| F2 | 적합도 기반 개인화 추천 | 인기순이 아닌 내 유형 기준 |
| F3 | 문화 충돌 예측 및 방문 전 안내 | 준비 사항 + 대안 2곳 |
| F4 | 문화 이해 가이드 및 실체험 요약 | 이용 방법 3단계 + 3줄 후기 |
| F5 | 현장 실시간 안내 | 근접 알림(인앱) + 도착 안내 + 상황형 루트 |

### 타사앱(트리플) 대비 차이

| | 트리플 | SAIRO |
|---|---|---|
| 시제 | 여행 전 계획 | 지금 이 순간 |
| 목록 기준 | 저장한 곳·인기순 | 걸어서 몇 분·지금 영업중 |
| 바뀌는 이유 | 사용자가 편집 | 비 오면·문 닫으면 안내 |

## 기술스택

| 영역 | 기술 | 비고 |
|---|---|---|
| 프론트엔드 | Next.js 16 (App Router) | React 19 · TypeScript |
| 스타일링 | Tailwind CSS 4 | 모바일 퍼스트 |
| 상태 관리 | Zustand + React Query | 프로필: localStorage · 장소: 정적 JSON |
| 지도 | Kakao Maps SDK | 부산 지역 최적화 |
| 외부 API | TourAPI 4.0 (5종) | Vercel API Route 프록시 1개 |
| i18n | next-intl | EN / KO |
| 앱 빌드 | Capacitor | WebView 래핑 · Android Only |
| 배포 | Vercel + Play Store | 웹: Vercel · 앱: Play Store 내부 테스트 |

## 아키텍처 원칙

- **로그인 없음** — localStorage로 프로필 저장, Play Store "수집 데이터 없음" 신고 유지
- **서버 없음** — CFP 생성·추천 엔진 모두 클라이언트 사이드, 서버는 TourAPI 프록시 1개뿐
- **DB 없음** — 태깅 데이터는 정적 JSON 파일
- **포그라운드만** — 백그라운드 위치·FCM 사용 안 함

## 지역 특화

부산광역시 6개 권역: 해운대 / 광안리 / 남포동 / 자갈치 / 국제시장 / 감천문화마을

활어회·돼지국밥·밀면·포장마차·찜질방·해수온천·전통시장 흥정 등 사전 안내 한 번으로 체험 만족도가 크게 달라지는 자원이 밀집. 자갈치시장·국제시장·감천문화마을이 도보권에 인접해 하루 안에 서로 다른 유형의 문화 체험이 연속 발생합니다.
