# 영문 초안 대조표

시트에 영문 컬럼이 없어 코드에서 임시로 만든 문구입니다. **전부 초안(DRAFT)** 이고,
시트에 `*_en` 컬럼이 생기면 그쪽이 정본이 됩니다.

어색한 곳을 이 표에 바로 적어주시면 반영하겠습니다.
