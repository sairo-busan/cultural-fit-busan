**병목 2: 기획은 CF8로 넘어갔는데 코드만 CFP16 (0번 항목)**

정본 구글 시트와 피그마 `Page 2_최종` 이 모두 CF8이고, CFP16은 피그마에서 ARCHIVE 처리됐다. **코드만 CFP16에 남아 있다.**

| | 코드 (현재) | 정본 (CF8) |
|---|---|---|
| 축 | 4축 — 분위기 Q/V · 로컬 L/F · 음식 M/H · 이동 S/W | 3축 — 분위기 **C/E** · 장소 **L/F** · 경험 **D/V** |
| 유형 | 16종 (`QLMS` 등 4자리) | 8종 (`CLD`~`EFV` 3자리) |
| 문항 | 6문항 · 1~5 점수 매핑 | 3문항 · **−1/+1 이어붙이기** |
| 음식/매운맛 | 점수 축 | 축 아님 — **Hard Filter R013** |
| 동반인·걷기 | 진단 문항 | `travel_mode` · `child_age_group` 별도 문항 |

⚠️ `V` 가 CFP16에서는 "활기"(분위기), CF8에서는 "다양하게 경험"(경험)이다. **같은 글자가 다른 뜻이라 기계적 변환은 불가능하다.**
