## 대전제 (개발확인필요)
1. 프로필·행동 데이터는 서버로 보내지 않는다. 로그인은 계정 식별용이며, CFP와 이용 기록은 기기에 저장한다.
1. 로그인 없이 모든 핵심 기능을 이용할 수 있어야 한다. 심사 대응 요건이다.
1. UNKNOWN ≠ 0. 정보가 없는 항목은 계산에서 제외하고 가중치를 재분배한다.
1. 표시 정책은 설정값으로 전환한다. 로직은 하나, 표시만 두 가지.
js
```javascript
const CONFIG = {
  SHOW_SCORE: true,        // 공모전 true / 사업화 false
  DEFAULT_LOCALE: 'ko',    // 공모전 'ko' / 사업화 'en'
};
```

# 1. CFP — 4축 이분법 16유형
```plain text
CFP-QLMS
    │││└─ 이동   S Slow(여유) / W Walk(활보)
    ││└── 음식   M Mild(순함) / H Hot(매움)
    │└─── 로컬   L Local(현지) / F Familiar(익숙)
    └──── 분위기 Q Quiet(고요) / V Vivid(활기)
```
## 진단 4문항 → 축 판정
| 문항 | 축 | 선택 → 코드 |
| --- | --- | --- |
| Q1 어떤 곳이 더 편하세요 | 분위기 | 조용한 곳 → Q / 활기찬 곳 → V |
| Q2 낯선 방식도 괜찮으세요 | 로컬 | 현지인이 가는 곳 → L / 안내가 잘 된 곳 → F |
| Q3 매운 음식은 어디까지 | 음식 | 순한 편 → M / 매운 것도 괜찮 → H |
| Q4 오늘 얼마나 걸으실 수 | 이동 | 가까운 곳 위주 → S / 많이 걸어도 → W |
## 축 → 척도 환산
계산에는 코드가 아니라 환산값을 쓴다.
js
```javascript
const CFP_SCALE = {
  Q: { noise_pref: 2, crowd_tolerance: 2 },
  V: { noise_pref: 4, crowd_tolerance: 4 },
  L: { local_pref: 4, english_need: 0 },
  F: { local_pref: 2, english_need: 2 },
  M: { spice_tolerance: 2 },
  H: { spice_tolerance: 4 },
  S: { max_walk_min: 10, stay_long: true },
  W: { max_walk_min: 20, stay_long: false },
};
```
## 건너뛰기 → 프리셋
| 프리셋 | 코드 |
| --- | --- |
| 혼자 조용히 | QLMS |
| 부산 미식 투어 | VLHW |
| 처음이라 무난하게 | QFMS |
## 저장
```plain text
cfp_code    "QLMS"
cfp_scale   { noise_pref: 2, local_pref: 4, spice_tolerance: 2, max_walk_min: 10, ... }
```
cfp_code는 표시용, cfp_scale은 계산용이다.

# 2. 전체 흐름 8단계
```plain text
1. 프로필 로드 (localStorage: cfb_profile)
      └ 없거나 Confidence < 40 → 4~7 생략, 거리순 폴백

2. 후보 수집
      └ 위치기반 관광정보 조회 + 자체 태깅 데이터 조인 (content_id)

3. Hard Filter  ← 점수 계산 전에 제외
      ├ 영업 종료
      ├ coverage < 40
      ├ 설정 반경 초과 (CFP 이동축: S 10분 / W 20분)
      ├ 24시간 내 이미 알림한 장소 (F5)
      ├ 현재 루트에 이미 포함
      └ 우천 시 실외 + 비 가림 없음

4. 축별 상태 판정
      ├ MATCH     → 축 점수 산출
      ├ MISMATCH  → 0점 + F3 안내 대상
      └ UNKNOWN   → 계산에서 제외

5. 가중치 재분배
      └ UNKNOWN 축 가중치를 나머지에 비례 배분 후 100으로 정규화

6. Fit 산출
      └ Σ (축 점수 × 재분배 가중치) / 100

7. 상황 보정
      ├ 우천 실외        −15
      ├ 시간대 불일치    −10
      ├ 세션 내 재노출    −20
      └ 지나친 곳(S43)   −10

8. 컷오프 60 → 카테고리 배정 → 근거 생성 → 정렬
```

# 3. Coverage — 장소 노출 자격
태깅 시트에서 자동 계산되어 JSON에 포함된다. 클라이언트는 읽기만 한다.
| 조건 | 점수 |
| --- | --- |
| tip_type ≠ none AND tip_headline 작성 | +30 |
| info(이용 방법) 작성 | +25 |
| pro AND con 모두 작성 | +20 |
| 이미지 존재 | +15 |
| 5축 전부 입력 | +10 |
| 구간 | 처리 |
| --- | --- |
| 70+ | 정상 노출 |
| 40~69 | 노출하되 순위 하향, F3·F4 섹션 숨김 |
| < 40 | Hard Filter로 제외 |
---
# 4. 축별 단계형 점수
0/100 이분법을 쓰지 않는다. 미묘한 차이가 사라져 순서가 뭉개진다.
| 축 | 100 | 중간 | 0 |
| --- | --- | --- | --- |
| 매운맛 | spice_level ≤ tolerance | 1단계 초과 → 40 | 2단계 이상 초과 → 0 + F3 |
| 분위기 | |noise_level − noise_pref| = 0 | 1 → 70 / 2 → 40 | 3 이상 |
| 로컬 | |local_depth − local_pref| ≤ 1 | 2 → 60 | 3 이상 → 20 |
| 이동 | 5분 이내 | 10분 80 / 15분 60 / 20분 30 | 초과 → Hard Filter |
| 영어 | english_support ≥ english_need | 1단계 부족 → 50 | 2단계 부족 → 0 + F3 |

# 5. 가중치
| 축 | 가중치 | CFP 대응 | 사용 컬럼 |
| --- | --- | --- | --- |
| 분위기 | 30 | Q / V | noise_level crowd_level |
| 로컬 깊이 | 25 | L / F | local_depth english_support |
| 음식·매운맛 | 25 | M / H | spice_level |
| 이동 거리 | 20 | S / W | mapx mapy (haversine → 80m/분) |
v1.0의 5축(동반유형·문화경험 분리)에서 4축으로 줄었다. CFP가 4축이므로 가중치도 4개로 맞춘다.
## 재분배 예시 — 카페(음식 축 해당 없음)
```plain text
음식 25 제외 → 나머지 합 75 → 100으로 정규화

분위기  30 → 40.0
로컬    25 → 33.3
이동    20 → 26.7
```

# 6. Confidence — 개인화 노출 강도
```plain text
Confidence = 실제 평가된 가중치 합 ÷ 100
```
| 구간 | 처리 |
| --- | --- |
| 70+ | 개인화 카테고리 정상 노출 |
| 40~69 | 카테고리 노출 + 더 알려주시면 정확해집니다 |
| < 40 | 거리순 폴백 · 상황 카테고리만 · Fit 계산 생략 |
프로필 없이 둘러보기와 진단 건너뛰기 사용자가 여기 해당한다.

# 7. 점수 표시 — 공모전 / 사업화
## 공모전 (SHOW_SCORE: true)
```plain text
82% 잘 맞아요
조용한 곳을 찾으신다면 창밖이 계속 바다입니다.
```
- 최종 점수를 정수 퍼센트로 표시
- 근거를 반드시 함께 노출한다. 점수만 띄우면 심사에서 산출 근거를 요구받는다
- 근거는 MATCH 상위 2개 축의 이유 문장
## 사업화 (SHOW_SCORE: false)
```plain text
조용한 곳을 찾으신다면 창밖이 계속 바다입니다.
```
- 점수 미표시. 순서 자체가 결과
- 개인화 카테고리와 이유 문장만
계산 로직은 완전히 동일하다. 표시 레이어만 분기한다.

# 8. 상태 지표 막대 — 신규
S20 상세와 S44 도착 안내에 표시한다. 적합도 계산과 별개로, 장소의 현재 상태를 보여주는 표시 전용 값이다.
## 실시간 상황 · 4축 고정
| 축 | 산출 | 1~5 환산 |
| --- | --- | --- |
| 혼잡도 | 현재 시각 vs crowd_peak / crowd_calm | peak → 4~5 / calm → 1~2 / 그 외 → crowd_level |
| 운영 여부 | 소개정보 조회 영업시간 | 영업중 5 / 마감 임박 3 / 종료 1 |
| 날씨 적합 | 날씨 API × weather_type | 실내 우천 5 / 실외 우천 1 / 맑음 4 |
| 거리 | haversine → 80m/분 | 5분 5 / 10분 4 / 15분 3 / 20분 2 |
각 막대 아래 한 줄 안내를 함께 표시한다. 막대만 있으면 그래프고, 안내가 붙어야 가이드다.
```plain text
혼잡도    ▮▮▯▯▯   한산한 편
          14~16시가 가장 여유롭습니다
```
## 장소 특성 · 유형별 3개 선택
| 장소 유형 | 표시 축 |
| --- | --- |
| 식음형 | 매운맛 · 1인 적합 · 영어 |
| 시장형 | 로컬 · 영어 · 예산 |
| 해양·야경형 | 소음도 · 예산 · 실내외 |
| 문화역사형 | 로컬 · 예산 · 소음도 |
spice_level = 0(음식점 아님)이면 매운맛 축은 표시하지 않는다.
## 표시하지 않는 것
대기 시간 — 실시간 데이터가 없다. 추정값을 표시하면 거짓이 된다.

# 9. 로그인 — 신규
## 원칙
| 항목 | 정책 |
| --- | --- |
| 방식 | 자체 ID (SNS 연동 미사용) |
| 필수 여부 | 선택. 비로그인 경로 필수 유지 |
| 저장 위치 | 계정은 서버, CFP·이용 기록은 기기 |
| 심사용 계정 | openapi / 2026openapi! |
SNS 로그인을 쓰지 않는 이유: 카카오·네이버는 일반 사용자 개방에 검수 절차가 걸릴 수 있고, 심사자가 로그인하지 못하면 평가가 불가능해진다.
## 비로그인 시 동작
| 기능 | 비로그인 |
| --- | --- |
| CFP 진단 | ✅ |
| 추천·상세·안내 | ✅ |
| 현장 안내 | ✅ |
| 저장함 | ✅ (기기 저장) |
| 기기 간 동기화 | ❌ 로그인 시에만 |
로그인은 기기 간 프로필 동기화가 유일한 차이로 설계한다. 심사자가 로그인 없이 전 기능을 확인할 수 있어야 한다.
## 개인정보 영향
로그인 도입으로 이메일·비밀번호 수집이 발생한다. 아래를 함께 갱신해야 한다.
- 개인정보처리방침
- 구글 콘솔 데이터 안전 섹션 (현재 "수집 없음"으로 신고됨)

# 10. 개인화 카테고리
점수 대신 화면에 나오는 묶음이다.
| 카테고리 | 조건 |
| --- | --- |
| 비를 피할 수 있는 곳 | weather_type = indoor AND 영업중 |
| 혼자 앉기 좋은 곳 | fit_solo ≥ 4 |
| 매운 것 없이 로컬 음식 | spice_level ≤ 2 AND local_depth ≥ 3 |
| 지금 문 연 야경 | best_time = night AND 영업중 |
| 사람 적은 시간 | crowd_level ≤ 2 또는 현재 crowd_calm |
| 현지인 많은 곳 | local_depth ≥ 4 |
카테고리 구성 = CFP 코드 + 현재 상황(날씨·시간)
| CFP 축 | 우선 노출 카테고리 |
| --- | --- |
| Q | 사람 적은 시간 · 혼자 앉기 좋은 곳 |
| V | 현지인 많은 곳 |
| L | 현지인 많은 곳 · 매운 것 없이 로컬 음식(M일 때) |
| F | — |
| M | 매운 것 없이 로컬 음식 |
| H | — |

# 12. 계산 로그 — 개발 중 필수
js
```javascript
console.debug('[fit v2.0]', contentId, {
  cfp: 'QLMS',
  hardFilter: 'pass',
  states:  { mood:'MATCH', local:'MATCH', spice:'MISMATCH', distance:'MATCH' },
  scores:  { mood:100, local:100, spice:40, distance:80 },
  weights: { mood:30, local:25, spice:25, distance:20 },
  adjust:  { rainOutdoor:0, timeMismatch:-10 },
  final:   82,
  reasons: ['조용한 곳', '현지인이 가는 곳'],
  bars:    { crowd:2, open:5, weather:5, distance:4 }
});
```
심사 시연 중 근거 질문이 들어오면 개발자 도구로 즉시 확인 가능하다.
