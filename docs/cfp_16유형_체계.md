# CFP — Cultural Fit Profile 16유형 체계

SAIRO (Cultural Fit Busan) / 2026-08-11 / v1.0

---

## 1. 개념

여행자의 문화 수용 성향을 **4개 축의 이분법**으로 나누어 16가지 유형으로 분류한다.
각 유형은 4자리 알파벳 코드를 가지며, 이 코드가 장소 추천·안내 문구·카테고리 구성의 기준이 된다.

```
CFP-QLMS
    │││└─ 이동  S(Slow) / W(Walk)
    ││└── 음식  M(Mild) / H(Hot)
    │└─── 로컬  L(Local) / F(Familiar)
    └──── 분위기 Q(Quiet) / V(Vivid)
```

---

## 2. 4개 축

### 축 1 — 분위기 · Atmosphere

| 코드 | 이름 | 성향 | 매칭 컬럼 |
|---|---|---|---|
| **Q** | Quiet · 고요 | 사람 적고 조용한 곳에서 편안함 | `noise_level` 낮음, `crowd_level` 낮음 |
| **V** | Vivid · 활기 | 북적이고 에너지 있는 곳을 즐김 | `noise_level` 높음, `crowd_level` 높음 |

### 축 2 — 로컬 깊이 · Depth

| 코드 | 이름 | 성향 | 매칭 컬럼 |
|---|---|---|---|
| **L** | Local · 현지 | 현지인이 가는 곳, 낯선 방식도 시도 | `local_depth` 4~5 |
| **F** | Familiar · 익숙 | 안내가 잘 되어 있고 예측 가능한 곳 | `local_depth` 1~2, `english_support` 2 |

### 축 3 — 음식 · Palate

| 코드 | 이름 | 성향 | 매칭 컬럼 |
|---|---|---|---|
| **M** | Mild · 순함 | 맵거나 향 강한 음식은 부담 | `spice_level` 0~2 |
| **H** | Hot · 매움 | 매운맛·강한 향도 즐김 | `spice_level` 3~5 |

### 축 4 — 이동 · Pace

| 코드 | 이름 | 성향 | 매칭 컬럼 |
|---|---|---|---|
| **S** | Slow · 여유 | 적게 움직이고 한 곳에 오래 | 도보 10분 이내, 체류 길게 |
| **W** | Walk · 활보 | 많이 걷고 여러 곳을 | 도보 20분까지, 체류 짧게 |

## 4. 진단 문항 — 4문항 이분법

기존 5문항 다지선다에서 **4문항 이분법**으로 변경한다.
각 문항이 축 하나를 결정하므로 4문항이면 16유형이 확정된다.

### Q1 · 분위기 → Q / V

> **어떤 곳이 더 편하세요?**
> 부산에는 조용한 골목과 북적이는 시장이 모두 있습니다.

| 선택지 | 결과 |
|---|---|
| 사람 적고 조용한 곳<br>혼자 걷기 좋은 골목과 한적한 카페 | **Q** |
| 사람 많고 활기찬 곳<br>시장의 소리와 북적이는 거리 | **V** |

### Q2 · 로컬 깊이 → L / F

> **낯선 방식도 괜찮으세요?**
> 현지인이 가는 곳은 안내가 없을 때가 많습니다.

| 선택지 | 결과 |
|---|---|
| 현지인이 가는 곳이 좋아요<br>주문 방식이 낯설어도 시도해보는 편 | **L** |
| 안내가 잘 된 곳이 편해요<br>영어 메뉴판이 있으면 마음이 놓임 | **F** |

### Q3 · 음식 → M / H

> **매운 음식은 어디까지 괜찮으세요?**
> 부산 대표 음식 중에는 매운 것이 많습니다.

| 선택지 | 결과 |
|---|---|
| 순한 편이 좋아요<br>맵지 않은 메뉴를 우선 안내 | **M** |
| 매운 것도 괜찮아요<br>돼지국밥 부추무침, 밀면까지 | **H** |

### Q4 · 이동 → S / W

> **오늘 얼마나 걸으실 수 있나요?**
> 남은 시간에 맞춰 동선을 짜드립니다.

| 선택지 | 결과 |
|---|---|
| 가까운 곳 위주로 천천히<br>두세 곳에 오래 머무는 편 | **S** |
| 많이 걸어도 괜찮아요<br>여러 곳을 두루 보고 싶은 편 | **W** |

### 건너뛰기

프리셋 3종으로 대체한다.

| 프리셋 | 코드 |
|---|---|
| 혼자 조용히 | **QLMS** |
| 부산 미식 투어 | **VLHW** |
| 처음이라 무난하게 | **QFMS** |

## 5. 축별 척도 환산

이분법 선택을 1~5 척도로 환산하여 추천 계산에 사용한다.

| 축 | 선택 | 환산값 | 사용 |
|---|---|---|---|
| 분위기 | Q | `noise_pref = 2` | 소음도 매칭 |
| | V | `noise_pref = 4` | |
| 로컬 | L | `local_pref = 4` | 로컬 깊이 매칭 |
| | F | `local_pref = 2` | |
| 음식 | M | `spice_tolerance = 2` | 매운맛 매칭 |
| | H | `spice_tolerance = 4` | |
| 이동 | S | `max_walk = 10분` | 거리 필터 |
| | W | `max_walk = 20분` | |

## 8. 상태 막대 — 화면 표시

장소 상세(S20)와 도착 안내(S44)에 표시한다.

### 실시간 상황 · 4축 고정

```
지금 이곳은                      18:30 기준

혼잡도    ▮▮▯▯▯   한산한 편
          14~16시가 가장 여유롭습니다
운영      ▮▮▮▮▮   영업 중 · 22시 마감
날씨      ▮▮▮▮▯   실내라 비를 피할 수 있어요
거리      ▮▮▮▮▯   도보 4분
```

### 장소 특성 · 유형별 3개 선택

```
이 장소는

매운맛    ▮▮▮▯▯   보통
          "덜 맵게" 요청할 수 있습니다
영어      ▮▮▯▯▯   메뉴판만
로컬      ▮▮▮▮▯   현지인이 많은 편
```

| 장소 유형 | 표시 축 |
|---|---|
| 식음형 | 매운맛 · 1인 적합 · 영어 |
| 시장형 | 로컬 · 영어 · 예산 |
| 해양·야경형 | 소음도 · 예산 · 실내외 |
| 문화역사형 | 로컬 · 예산 · 소음도 |

`spice_level = 0`(음식점 아님)이면 매운맛 축은 표시하지 않는다.

## 9. 태깅 시트 추가 컬럼

| 컬럼 | 값 | 용도 |
|---|---|---|
| `crowd_peak` | `11-15` | 이 시간대 → 막대 4~5칸 |
| `crowd_calm` | `14-16` | 이 시간대 → 막대 1~2칸 |
| `cfp_match` | `QLMS,QLMW` | 이 장소에 특히 잘 맞는 유형 (선택) |

`cfp_match`는 비워도 축 계산으로 매칭되지만, 채우면 정확도가 올라간다.
