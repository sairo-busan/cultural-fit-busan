# FE-FEAT-020: 저장 폴더 실험 화면 (lab/saved-folders)

저장한 장소를 사용자가 직접 만든 폴더로 나누고, 폴더 안에서 지역으로 거르며 지도로 보는 숨은 실험 화면. 인스타그램 저장 · 컬렉션 구조가 장소 저장에도 맞는지 확인하는 것이 목적이다.

## Problem

10/29 회의 할 일: 저장 기능 — 유나 스케치 · 인스타그램 저장 기능 참고.

- 저장 탭은 지역 칩 하나로만 거른다. 여행 · 목적별로 묶어 둘 수 없다.
- 유나 스케치의 폴더(해운대 · 광안리 · 송정)는 구 · 군 단위가 아니라 주소에서 자동으로 나눌 수 없다. 사용자가 직접 만드는 폴더면 그대로 표현할 수 있다.

## Scope

### 포함

| 화면 · 파일 | 내용 |
|---|---|
| 저장한 곳 `/lab/saved-folders` | 폴더 최근 2개(2열) · 전체 보기 · 새 폴더 버튼 · 모든 장소 목록 · 지역 칩 · 정렬 · 관리 |
| 전체 폴더 `/lab/saved-folders/all` | 2열 격자. 폴더 그림 · 이름 · 개수 · 새 폴더 버튼 |

| 장소 관리 | 원형 선택 · 전체 선택. 하단 "저장 해제"(폴더 안에서는 "폴더에서 빼기") · "폴더에 넣기" |
| 폴더에 넣기 시트 | 폴더 목록(여러 개 선택) · 새 폴더 |
| 새 폴더 · 이름 바꾸기 시트 | 이름(최대 20자) · 글자 수 |
| `src/lib/storage.ts` | `cfb_saved_folders` 키와 읽기 · 만들기 · 이름 변경 · 삭제 · 장소 넣기 · 빼기 함수 추가 |
| `src/app/[locale]/lab/link-save/saved/SavedLinks.tsx` | 제목 "링크로 저장한 곳" → "링크 기록" |
| `messages/ko.json` · `messages/en.json` | 이 화면 문구 |

### 제외

- 운영 저장 탭(`/saved`) · S20 · 탭바 · `cfb_saved` 구조
- 카탈로그 밖 장소 저장 · 링크 기록에서 폴더로 넣기 — 카카오 응답 저장 제한 확인 뒤
- 장소 유형 칩 — 카탈로그에 식당 · 카페가 없다(운영 API 118곳: 12번 88 · 14번 15 · 38번 13 · 28번 2 · 39번 0)
- 폴더 합치기 · 검색 · 공개 범위 · 공동 폴더 · 내 위치 주변 저장 장소

## 데이터

```ts
type SavedFolder = {
  id: string;
  name: string; // 1~20자, 중복 불가
  createdAt: string;
  places: { id: string; addedAt: string }[]; // id 는 카탈로그 contentId
};
```

| 항목 | 규칙 |
|---|---|
| 목록 원천 | `cfb_saved` + `/api/recommend?limit=120`. 카탈로그에 없는 곳은 표시하지 않는다 |
| 폴더 소속 | 한 장소는 여러 폴더에 들어갈 수 있다. 폴더에 넣어도 전체에는 남는다 |
| 저장 해제 | 전체와 모든 폴더에서 보이지 않는다. 다시 저장하면 들어 있던 폴더에 돌아온다 |
| 폴더 개수 · 사진 | 지금 저장돼 있는 곳만 센다. 폴더 앞면 뒤로 사진이 있는 곳을 최근 넣은 순으로 최대 2장 보여 준다. 사진이 없으면 기본 폴더 |
| 폴더 정렬 | 가장 최근에 장소를 넣은 폴더가 앞 |
| 지역 칩 | `districtLabel(addr1)`, 영문은 `districtLabelEn`. 있는 지역만, 1개 이하면 줄을 숨긴다 |
| 정렬 | 저장한 곳은 최근 저장순(`savedAt`), 폴더는 최근 넣은 순(`addedAt`). 적합도순은 CF8 3축 매칭, 점수 대신 등급 문구, 진단 전에는 고를 수 없다 |

## 화면 상태

| 상황 | 처리 |
|---|---|
| 저장 0곳 | "아직 저장한 곳이 없어요" + 추천 보러 가기 |
| 폴더 0개 | 폴더 영역에 새 폴더 안내 |
| 빈 폴더 | 지도 없음. "이 폴더에 넣은 곳이 없어요" + 장소 넣기 → 장소 관리 |
| 없는 폴더 id | "폴더를 찾을 수 없어요" + 저장한 곳으로 |
| 고른 지역의 마지막 장소가 빠짐 | 지역 칩을 전체로 |
| 폴더 이름 비어 있음 · 중복 | 만들지 않고 입력칸 아래에 이유 표시 |
| 저장 해제 · 폴더 삭제 | 확인 창(위험색). 폴더 삭제는 장소가 저장한 곳에 남는다고 알린다 |
| 카탈로그 실패 | 다시 시도 |

## 지도 (폴더 상세)

| 항목 | 규칙 |
|---|---|
| 위치 | 제목 아래 192px, 스크롤해도 위에 고정 |
| 핀 | 지금 보이는 목록 순서의 번호. 행의 번호와 같다. 지역 칩을 고르면 그 지역 핀만 남기고 범위를 다시 맞춘다 |
| 지금 보는 곳 | 처음에는 첫 장소를 잉크색으로. 핀을 누르면 그 핀으로 바뀌고 목록이 해당 행으로 이동한다 |
| 행 누름 | `/place/{contentId}` 로 이동 |
| 장소 1곳 | 그 장소 중심 |
| 지도 로딩 실패 | 지도 칸에 안내 문구, 목록은 그대로 |

## Acceptance Criteria

1. `LINK_LAB_ENABLED=true` 가 아니면 세 경로 모두 404다.
2. 폴더를 만들고 이름을 바꾸고 삭제할 수 있고, 새로고침 뒤에도 남는다.
3. 여러 장소를 골라 여러 폴더에 넣고 뺄 수 있다. 이미 들어 있는 곳은 중복되지 않는다.
4. 폴더 삭제 · 폴더에서 빼기는 저장한 곳(`cfb_saved`)을 바꾸지 않는다.
5. 저장을 해제하면 전체와 폴더 목록 · 개수에서 함께 빠진다.
6. 폴더 상세의 지역 칩이 목록과 지도 핀을 함께 거른다.
7. 운영 저장 탭 · S20 · 피드 동작과 `cfb_saved` · `cfb_link_saves` 구조는 바뀌지 않는다.
8. 저장값이 깨져 있어도 화면이 죽지 않고 빈 폴더 목록으로 시작한다.
9. ko · en 모두 문구 키가 빠지지 않는다.
10. `npm run lint` · `tsc --noEmit` · 웹 빌드 · `BUILD_TARGET=app` 빌드 통과.
