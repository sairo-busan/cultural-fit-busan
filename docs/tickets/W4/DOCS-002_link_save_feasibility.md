# DOCS-002 · 10/20 회의 후속: 링크 저장 가능성 조사와 실행 계획

- 작성: 2026-10-29
- 담당: 소피. 에린 담당으로 적힌 후속 항목은 분담 제안이며 배정 확정이 아님.
- 상태: 1차 문헌·코드 조사 완료 / API 실호출·실기기 검증 대기
- 브랜치: `codex/link-save-feasibility`

## 문제와 목표

10/20 회의에서 소피·에린에게 링크·주소의 장소 저장 가능성과 플랫폼별 API·정책 조사가
배정됐다. 링크 보관, 게시물 정보 조회, 실제 장소 식별, 추천 활용을 나눠 초기 구현 범위를 정한다.
회의 연도는 원문에 없으며, 기한의 달력 날짜는 원문 확인 전 확정하지 않는다.

## 범위

- 현재 저장 기능·Android 공유 수신 구조 확인
- Instagram / Facebook / YouTube / TikTok / 카카오·네이버·Google 지도와 주소 입력 조사
- 공식 문서의 확인 사실, 설계 제안, 미검증 항목 구분
- 소피 실행 순서·예상 작업량·완료 기준과 에린 확인 항목 작성
- 앱 기능, DB, 개인정보처리방침, 추천 가중치, 분석 도구는 변경하지 않음
