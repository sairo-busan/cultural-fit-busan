## Problem

### ① 목록 사진 넘기기 깜빡임

| 화면 | 아이폰 |
|---|---|
| S20 상세 맨 위 사진 | 매끄럽게 넘어간다 |
| S10 목록 카드 사진 | 깜빡이고 잘 안 넘어간다 |

두 곳 모두 같은 `PhotoSwipe` 를 쓴다. 다른 점은 목록 카드만 링크 전체에 눌림 효과(`active:opacity-70`)가 있다는 것(`PlaceCard.tsx`).
안드로이드 · PC 크롬은 스크롤이 시작되면 `:active` 를 푼다. iOS Safari 는 손을 뗄 때까지 유지해, 스와이프 내내 카드가 흐려졌다 돌아온다. 스크롤 중인 요소의 상위 투명도가 바뀌면 WebKit 이 다시 그리면서 넘기기가 끊긴다.

### ② 오디오 가이드 뒤로 버튼 선택 상태

오디오 가이드는 `<dialog>` 를 `showModal()` 로 연다(`Docent.tsx`). 이때 브라우저는 첫 번째 포커스 가능한 요소 — 뒤로 버튼 — 에 포커스를 준다.
전역 `:focus-visible` 테두리(`globals.css`)가 이 버튼에 그려진 채 남는다. 아이폰에서만 보인다 — Safari 가 스크립트로 옮긴 포커스에도 `:focus-visible` 을 적용하는 것으로 본다(아이폰 확인 전 추정).

안드로이드 에뮬레이터 · PC 크롬은 수정 전에도 테두리가 안 보여 전후 화면이 같다. 확인은 PR 미리보기를 아이폰에서 여는 수밖에 없다. 첫 포커스를 옮길 제목은 키보드로 닿지 않는 자리(`tabIndex={-1}`)라 테두리를 끈다 — 뒤로 · 닫기 버튼의 테두리는 그대로다(qa:ui U3).

### ③ 개인정보처리방침 아래 구분선

`SettingRow` 가 줄마다 `border-b` 를 그린다. 섹션의 마지막 줄에도 선이 남는다.

### ⑤ 영업시간이 한 줄로 붙는다

TourAPI 원문에 줄바꿈이 없다. 부평깡통시장은 `[시장]08:00~20:00[야시장]19:00~03:30※ 점포 별로 영업시간은 상이할 수 있음` 한 덩어리로 온다(프록시로 원문 확인 — 적재 과정에서 잘린 것이 아니다).

화면은 줄바꿈을 살려 그리므로(`whitespace-pre-line`) 응답에서 나눈다. `pickOperationValue` 한 곳을 지나는 영업시간 · 휴무일이 한국어 · 영문 모두 대상이다.

DB 실측 — 값 110개(장소 89곳)가 바뀌고 그중 앱에 나오는 곳이 25곳. 잘못 잘린 값 0건.

### ④ 여행 조건 화면 고정 영역

화면이 `h-dvh` 세로 배치이고 제목 블록(`오늘 여행은 어떤가요?` + 설명)이 `shrink-0` 으로 스크롤 밖에 있다. 헤더 · 제목 · 하단 버튼이 모두 고정이라 가운데 선택지 영역만 스크롤된다.

## Scope

### 포함

```
① PlaceCard      active:opacity-70 → 사진(role=region)을 누를 때는 제외
                 제목 · 설명을 누르면 전처럼 흐려진다

② Docent          dialog 첫 포커스를 뒤로 버튼 대신 제목(h1)으로
                 화면 낭독기도 열리자마자 장소 이름을 읽는다

③ SettingRow      섹션의 마지막 줄은 아래 선 없음 (last:border-b-0)
                 → 여행 스타일의 "취향 진단 다시 하기" 아래 선도 같이 빠진다

⑤ placeDetail     영업시간 · 휴무일을 구분 기호마다 줄 나누기
                 [구분] 앞 · ※ 앞 · 영문 * 앞(괄호 안은 제외) · "- 항목" 앞
                 "09:30 - 17:30" 같은 시각 범위 하이픈과 줄 끝의 / 는 건드리지 않는다
                 서버 응답이라 배포하면 이미 나간 앱(v1.1 · v1.2)에도 반영된다

④ trip-setup      제목 블록을 스크롤 영역 안으로. 뒤로 버튼 헤더와 하단 버튼만 고정
   ┌─────────────────────────┐
   │ ‹                       │  고정
   ├─────────────────────────┤
   │ 오늘 여행은 어떤가요?     │  ↑ 스크롤과 함께 올라간다
   │ 설명                     │
   │ ▸ 동반                   │
   │ ▸ 보행 …                 │
   ├─────────────────────────┤
   │ [나중에]  [ 추천받기 ]    │  고정
   └─────────────────────────┘
```
