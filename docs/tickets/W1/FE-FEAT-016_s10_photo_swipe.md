## Problem

- **현재 동작**: 추천 카드는 사진 한 장(`firstImage`)만 그린다. 목록 API 에 `images` 가 있는데 쓰지 않는다.
- **기대 동작**: 카드에서 사진을 옆으로 넘기고, 여러 장이면 몇 번째인지 보인다.
- **배경**: FE-FEAT-014 때는 PR #31(S20 상세)이 열려 있어 갤러리 코드를 건드리지 않았다. #31 은 머지됐다.

사진이 없는 곳(4곳)은 지금 회색 판에 "사진 없음" 글자만 나온다. 카드가 통째로 빈 판이 되어 눈에 띈다.

## Strategy

### Step 1: 사진 없음 기본 이미지

`PlaceCard` · `PlaceRow` · S20 의 "사진 없음" 글자를 기본 그림으로 바꾼다. 쓰지 않게 된 `place.noPhoto` 는 지운다.

### Step 2: `PhotoSwipe` 분리

`PlaceContent` 의 사진 목록 · `photoIndex` · `scrollToPhoto` · `GalleryControls` 를 공용 컴포넌트로 옮긴다.
S20 은 `PhotoSwipe` 위에 뒤로 버튼 · 저장을 얹는 형태가 된다. **이 Step 에서는 화면이 달라지지 않아야 한다.**

### Step 3: `PlaceCard` 적용

카드 사진 자리를 `PhotoSwipe` 로 바꾼다. 2장 이상일 때만 점을 그린다(결정 2 · 3 · 3-1).

### Step 4: 검증

`tsc` · `lint` · `build` 와 화면 확인. 화면은 개발 서버 주소와 확인 항목을 정리해 서영님께 부탁한다.

### 구현

- `PhotoSwipe` — `hoverArrows` 로 카드(마우스 올림)와 S20(항상)을 가른다. 화살표 클릭은 `preventDefault` 로 카드 링크 이동을 막는다
- 점 — 사진 수만큼 한 줄로 그리고 줄을 `translate` 로 옮겨 5개 창에 맞춘다. 점 크기는 `scale` 로 바꿔 창 폭(54px)이 변하지 않는다
- 화살표 — `pointer-fine:grid` (기본 숨김). 카드 마우스 올림은 `@media (hover: hover)` 안에서만 적용된다
- 카드 포커스 테두리는 `after:rounded-[inherit]` 로 둥근 모서리를 따른다

### 후속 (별도 티켓)

**S10 카드 링크 구조** — 카드 전체가 링크 하나라, 그 안에 사진 영역(`tabIndex=0`) · 저장 · 화살표가 들어 있다.

| 문제 | 영향 |
|---|---|
| 링크 안 조작 요소 | HTML 규칙 위반. 브라우저가 처리해 탭 · 밀기 · 저장은 동작한다 |
| 링크 이름 | 화면 낭독기가 "사진 · 저장 · 이전 사진 · 다음 사진 · 1 / 11 · 제목 …" 을 한 링크로 읽는다 |

바꿀 구조:

```
<article>                                  링크 아님 · has-[a:active]:opacity-70
  PhotoSwipe
  ├ 사진마다 <a href> (tabIndex=-1 · aria-hidden)   사진 탭 → 상세
  ├ 저장 버튼                                        링크 밖
  └ ‹ › 화살표                                       링크 밖
  메타
  <h3><a href> 제목 </a></h3>              유일한 링크 · after:inset-0 덮개로 글 영역 전체
  설명
</article>
```

- `PhotoSwipe` 에 `href` 옵션 — 있으면 사진을 링크로 감싼다. S20 은 넘기지 않는다
- 화살표 클릭의 `preventDefault` 는 필요 없어진다
- 저장 탭 행(`PlaceRow`)은 저장 버튼이 이미 링크 밖이라 대상 아님
- 검증: 사진 탭 · 글 탭 → 상세 / 밀기 · 저장 · 화살표 → 이동 없음 / 화면 낭독기 링크 이름 · Tab 순서
