## Problem

온보딩 네 화면이 **각각 다른 시기에 만들어져 서로 다른 규칙**을 쓴다.
FLOW 01 은 사용자가 처음 보는 흐름이고 심사자도 여기서 시작한다.

| 화면 | 증상 |
|---|---|
| S00 | 문구가 한국어로 고정 — `/en` 에서도 "부산에 도착하셨나요?" |
| S00 | `LocaleDropdown` 이 localStorage `cfb-locale`(기본 `ko`)을 읽어 `/en` 에서도 KO 로 보이고, 골라도 경로가 바뀌지 않는다 |
| 공통 | 헤더 로고가 `/`(S00)로 간다 — 메인은 추천 탭(`/feed`)이다 |
| S01 | 뒤로가 들어온 곳과 상관없이 항상 `/`(S00)로 간다 — 내 정보 → 다시 진단에서 뒤로를 누르면 S00 을 거쳐 추천으로 떨어진다 |
| S01 | 답을 누를 때마다 바로 저장된다 — 다시 진단 중 1~2문항만 바꾸고 나가면 새 답과 옛 유형(`cf8_code`)이 섞인다 |
| S02 | 결과 화면인데 결과처럼 보이지 않는다 — 유형명과 축 카드 3개 나열 |
| S02 | 분석 연출 문구(`LOADING_STEPS`)가 한국어 고정 |
| S02 | 다시 하기가 `window.location.href = "/onboarding"` — 앱(정적 export)에서는 `/onboarding/index.html` 이 없어 빈 화면 |
| S02 | 분석 연출이 `/profile` 을 열 때마다 돈다 — 진단 결과(`cf8_code`)가 이미 있어도 (유형 카드 · 새로고침 · 직접 진입) |

## Strategy

**화면 하나를 끝낼 때마다 멈추고 검토한다.** 도식은 목업(`mockup_onboarding.html`)의 확정안 기준이다.

### S00 시작 — 단계 안내형

```
SAIRO                        [한국어 | English]   지금 로케일이 채워짐
부산에 도착하셨나요?                              14 · sub
지금 갈 곳,
SAIRO가 골라드릴게요                              30
세 단계만 거치면 바로 안내해드릴게요                 17 · sub
① 취향 질문 3개에 답해요        30초면 끝나요
② 내 여행 캐릭터를 만나요        8가지 유형 중 하나예요
③ 지금 갈 만한 곳을 받아요       날씨와 시간대까지 보고 골라요
[              시작하기              ]            → S01
            먼저 둘러볼게요                        확인 대기
```

- 언어 두 칸은 `useLocale` 로 표시하고, 누르면 `router.replace(pathname, { locale })`
- `cf8_code` 가 있으면 `/feed` 로 넘긴다. 콘텐츠는 fade-in 으로 등장해 넘어가는 동안 랜딩이 스치지 않는다

### S01 취향 진단 — 한 문항씩

```
‹                                 나중에 할게요   ← 그만두기 모달
━━━━━━━━━━  ──────────  ──────────               진행 바 3칸
1 / 3 · 분위기                                   14 · sub
여행지에서 어떤 분위기에 더 끌리나요?              24 · 700
[ 차분하고 여유로운 공간            ]             연회색 → 고르면 잉크
[ 활기와 움직임이 느껴지는 공간      ]
                                                 하단 버튼 없음
```

| 동작 | 규칙 |
|---|---|
| 고르면 | 고른 버튼은 잉크로 남고, **나머지 선택지는 왼쪽으로 30px 밀리며 사라진다**(0.4초, 항목마다 0.04초씩 늦게). **0.7초 뒤** 다음 문항. 3번 문항을 고르면 저장 → 캐릭터 공개 |
| 동작 줄이기 | 밀림 없이 바로 다음 문항 |
| 진행 | 진행 바는 지금 문항까지 채움. 숫자는 질문 위 작은 줄 "n / 3 · 축 이름" |
| 선택지 | 한 줄 버튼. 라디오 동그라미 · 설명 문장 없음. Radix `RadioGroup` 의미(화살표 이동 · 스크린리더)는 유지 |
| 뺀 것 | 상단 단계 탭 · 문항 카드 · "1단계" 라벨 · 하단 결과 보기 버튼 · 안내문 |
| 참고 | 이 애니메이션은 이전 한 문항씩 버전(`15fc5d6`, `ADVANCE_DELAY = 700`)과 같은 값 |

문항 · 선택지 문장은 `QUIZ_TEXT` 그대로. 방향 A(한 화면 3문항 · "결과 보기 n/3")는 대안으로 목업에 남기고 팀 의견을 받는다.

#### 뒤로 · 저장 · 그만두기

| 상황 | 동작 |
|---|---|
| 2 · 3번 문항에서 뒤로 | 이전 문항. 고른 답은 화면 상태에 남는다 |
| 1번 문항에서 뒤로 | 들어온 화면으로. 기록이 없으면 S00 |
| 3번 문항 선택 | 답 · `cf8_code` 를 한 번에 저장 → 캐릭터 공개 → S02 |
| 중간에 나감 (뒤로 · 그만두기 · 앱 종료) | 아무것도 저장하지 않는다. 결과가 있으면 그대로 |

**그만두기 모달** (문구 확정 · 첫 진단의 보조 버튼 이동만 팀 확인 대기)

| 자리 | 결과 있음 (다시 진단) | 결과 없음 (첫 진단) |
|---|---|---|
| 링크 | 나중에 할게요 · Maybe later | 같음 |
| 모달 제목 | 다음에 고를까요? · Finish this later? | 지금 멈추면 추천을 볼 수 없어요 · You won't see picks yet |
| 모달 본문 | 지금 유형 그대로 추천을 볼 수 있어요. 고르던 답은 저장되지 않아요 · Your current type stays. Answers so far won't be saved. | 추천은 세 가지 답으로 만들어요. {n}개만 더 고르면 돼요 · Picks are built from three answers. Just {n} more. |
| 주 버튼 | 계속 고를게요 · Keep going | 같음 |
| 보조 버튼 | 그만할게요 → 추천 | 그래도 둘러볼게요 → 추천(빈 안내) — 팀 확인 대기 |

**재진입 토스트** (문구 확정)

| 조건 | 문구 |
|---|---|
| 답을 하나 이상 고른 채 나갔다가 같은 방문에서 S01 에 다시 들어옴 (sessionStorage 신호) | 고르던 답은 저장되지 않았어요. 처음부터 골라주세요 · Your answers weren't saved. Let's start again. |
| 결과가 있는 상태로 S01 에 들어옴 (다시 진단) | 끝까지 고르면 새 유형으로 바뀌어요 · Your type changes only when you finish |

두 조건이 겹치면 첫 줄만 띄운다.
