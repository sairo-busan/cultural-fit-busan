## Problem

- **현재 동작**: `cf8_code` 가 없으면 `useRecommendations` 가 `NEED_QUIZ` 를 내고, 추천 탭은 목록 없이 빈 화면 안내만 그린다.
- **기대 동작**: 진단 전에도 목록이 보인다. 상단 박스가 진단을 권한다.
- **배경**: S00 `먼저 둘러볼게요` 와 진단 중단 모달 `그래도 둘러볼게요` 가 모두 `/feed` 로 온다. 둘러보겠다고 고른 사람이 빈 화면을 만난다.

적합도를 못 쓰고 인기순 · 저장 수 · 영업 중 데이터도 없어, 정렬 기준은 CF8 장소축의 대표 명소 점수(`landmarkScore`)로 한다. 진단 전 목록 노출 · 정렬 기준 · 제외 항목(데이터 없는 필터 · 날씨 인과 문구)은 유나 확인.

| # | 상황 | 화면 |

| E1 | 조건(`trip_setup`)에 맞는 곳이 없음 | **현재 데이터로는 발생하지 않는다** — 조건을 가장 좁게 골라도(이동 약자 + 반려동물 + 실내 먼저) 8곳이 남는다. 필터는 확인된 불가(false)만 빼는데 운영 119곳에 무장애 false · 식당이 0곳이다. 기존 `feed.noResults` 분기는 그대로 두고 새로 그리지 않는다 |
| E2 | 목록 불러오기 실패 | **박스와 정렬 라벨을 숨기고** 기존 `feed.loadFailed` 재시도 안내만. 라벨은 보여줄 목록이 없어 의미가 없다 — 진단한 사용자의 실패 화면(`추천순`)도 같이 숨긴다. 목록을 못 받은 순간엔 박스의 "맞는 곳부터 보여드려요" 를 지킬 수 없고, 박스 버튼과 "다시 시도" 가 같은 검은 버튼이라 위계가 생기지 않는다. 다시 시도가 성공하면 박스가 나타난다. 공용 `EmptyState` 는 바꾸지 않는다 (S20 불러오기 실패와 같은 모양 유지) |
| E3 | 날씨 불러오기 실패 | 결정 8. 목록 · 라벨은 그대로, 날씨 자리에 안내 + ↻ |
| E4 | `cf8_code` 가 깨진 값 (구 CFP16 코드 · 빈 문자열) | 진단 전과 같다 (결정 7) |
| E5 | `landmarkScore` 가 없는 곳 | 맨 뒤. 운영 데이터엔 0곳이지만 적재가 필드를 비우는 일이 실제로 있다 — 2026-09-18 `addr1` · `mapX` · `mapY` 가 빈 곳 1곳이 목록 전체를 멈췄다(FE-BUG-004) |

## Strategy

### Step 1: 와이어프레임

진단 전 S10 과 예외 상황을 목업으로 비교해 정했다 — 결정 3(박스 A) · 4(본문 · 버튼) · 5(라벨) · 8(날씨 실패) · E2(박스 · 라벨 숨김) · E6(로딩). 피그마 `S10 추천 피드 [취향 미설정]`(`1038:1082`)에서는 정보 항목만 가져왔다.

박스 제목은 현행 유지로 정했다(결정 4). "유형 → 스타일" 통일은 추후.

### Step 2: 진단 전 정렬

`useRecommendations` 한 파일. 엔진(`recommendEngine` · `cf8Match`)은 바꾸지 않는다 — 빈 `cf8Code` 면 CF 축이 빠진다(에린 확인).

1. 조기 차단 `if (!cf8Code) { setError("NEED_QUIZ"); return; }` 를 지운다
2. `isCf8Code` 로 진단 여부를 판정한다 — 깨진 값도 진단 전(결정 7 · E4)
3. 진단 전이면 `rankPlaces(cf8Code: "")` 결과를 `landmarkScore` 내림차순으로 다시 정렬한다. 같은 점수는 엔진 순서를 유지한다 — 기존 코드에 없는 새 정렬
4. 진단 여부를 결과로 넘기고 `FeedError` 에서 `NEED_QUIZ` 를 뺀다

Step 3 전까지 추천 탭은 박스 없이 목록만 나오는 중간 상태다.

### Step 3: 상단 박스 · 정렬 라벨

`FeedContent` 에서 유형 카드 대신 박스를 그리고, 라벨을 진단 여부로 나눈다. `NEED_QUIZ` 빈 화면을 지운다. `FeedSkeleton` 도 같은 판정으로 박스 자리 · 라벨을 그린다(E6). `feed.needQuiz` 문구를 결정 4로 바꾼다.

### Step 4: 날씨 실패

`useRecommendations` 에 날씨 한 번 더 요청 · 날씨만 다시 불러오기를 넣고, `FeedContent` 머리말에 안내 + ↻ 를 그린다. `Weather` 에 모름(null)을 허용해 `selectWeatherScore` 가 null 을 돌려주게 한다(결정 8). 엔진 변경분은 PR 에서 에린 리뷰.

### Step 5: 검증

`tsc` · `lint` · `build` 와 화면 확인. 화면은 개발 서버 주소와 확인 항목을 정리해 서영님께 부탁한다.
