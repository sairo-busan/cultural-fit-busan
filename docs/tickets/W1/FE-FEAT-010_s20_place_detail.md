## Problem

`/place/[id]` 는 `mock-places.ts` 에서 값을 읽는다. 적합도 %·실시간 막대·날씨 문구가
박혀 있어 **실제 장소와 무관한 화면**이다.

저장도 옛 스키마(`string[]`)로 `cfb_saved` 에 쓴다. FE-FEAT-009 에서 `{ id, savedAt }`
으로 바꾼 뒤라, 상세에서 저장하면 저장 탭 목록이 비어 버린다.

## Strategy

### Step 1: 계약 타입 + 로컬 픽스처

`src/types/place.ts` 에 `PlaceDetail` 을 둔다(BE-FEAT-013 계약과 같은 모양).

BE 가 오기 전에는 시트 CSV · `places` 문서 · 영문 서비스로 만든 120곳 픽스처를 임시 라우트로 띄운다.
임시 라우트는 `.git/info/exclude` 에 넣어 커밋되지 않게 한다. 재적재 뒤에는 DB 실데이터로 다시 만들었다.

```
① 126119  부산 어린이대공원     갤러리 · 영업정보 · 이동 편의 안내가 다 있는 곳
② 2606221 영도 흰여울해안터널   사진 · 영업정보가 없는 곳
③ 128108  스포원파크           영문 가이드가 가장 짧은 곳
④ 2385666 국립부산과학관        영업시간 · 휴무일 영문이 있는 곳
```

### Step 2: 화면 뼈대

FE-FEAT-009 와 같이 `page.tsx` · `PlaceContent.tsx` · `PlaceSkeleton.tsx` 로 나눈다.

### Step 3: 히어로

가로 `scroll-snap` 갤러리. 2장 이상일 때만 `n / N`.
사진 위는 뒤로(기록 없으면 추천으로)만 둔다. 저장은 Step 5 하단 버튼, 도슨트는 FE-FEAT-013 의 제목 아래 카드다.

스와이프가 없는 입력도 넘길 수 있게 한다 — 마우스 · 트랙패드에서만 좌우 화살표(`pointer-fine`),
키보드는 갤러리에 포커스 후 ← →. 폰 화면은 목업 그대로다.

### Step 4: 머리 · 이유 · 그리드

```
중구 · 역사·문화            districtLabel · placeType   (en: Jung-gu · History & culture)
40계단 문화관광테마거리      nameKo / nameEn
피란 시절의 기억을 품은…     descKo / descEn
부산광역시 중구 …           addr1 / addr1En

[이 곳이 맞는 이유]         ko 이고 값이 있을 때만

영업시간 | 휴무일            둘 중 하나라도 40자 넘으면 둘 다 한 줄 전체 폭
실내·야외 | 반려동물          반려동물 조건은 ko 만, 값 아래 작게
전화     | 이동 편의          전화는 번호 모양이 있을 때만 전화 걸기 · 이동 편의는 누르면 아래 안내로
```

### Step 5: 문화 가이드 · 근처 · CTA

가이드 본문은 `자세히`(ko) / `en` 을 문단으로 나눠 그린다. `간단히` 는 S20 에 쓰지 않는다
— 자세히와 겹치고, 30초 도슨트 원고라 FE-FEAT-013 의 것이다.

놓치기 쉬운 것은 `사진 포인트 · 유의사항` 두 줄. 관람 순서는 120곳 중 119곳이 자세히 본문 문장과 같아 뺀다. 관람 순서 역할은 이후 시트의 이용 방법 단계가 맡는다(유나).
본문의 두 섹션은 임시다 — FE-FEAT-013 의 도슨트 화면으로 옮겨 간다.

함께 둘러볼 곳은 #21 을 그대로 쓴다. 가까운 곳이 늘 가깝지는 않아서 "근처" 라고 부르지 않는다 —
120곳 중 가장 가까운 곳까지 도보 중간값 7분, 15분 넘는 곳 27, 최대 134분.
직선거리라 20분 이내는 `도보 약 N분`, 넘으면 `N.Nkm` 로 적는다.

하단 고정 버튼은 `지도 보기 | 저장하기` 다. 저장이 주 버튼이다 — 앱 안에 남는 동작이고, 지도는 앱 밖으로 나간다.
길찾기는 구글맵 안에서 이어간다. 외국인 사용자에게 카카오맵은 설치돼 있지 않은 앱이다.

```
지도 보기   https://www.google.com/maps/search/?api=1&query={nameKo, 이름에 "부산" 이 없으면 " 부산"}
```

좌표만 넘기면 장소가 아니라 핀이 뜨고, 주소를 붙이면 검색 목록으로 떨어진다. 영문 화면도 한국어 이름을 쓴다.

### Step 6: BE-FEAT-013 도착 후

임시 라우트와 exclude 줄을 지우고 실데이터로 Verification 을 다시 돈다.
`mock-places.ts` 를 지우고, 응답 타입은 `lib/placeDetail.ts` · `lib/nearbyPlaces.ts` 의 정의를 가져다 쓴다.

## 알아둘 점

- **목록 행(추천 · 저장 탭)과 상세의 제목이 다르다.** 행은 한 줄 설명(`원도심과 부산항을 내려다보는 전망타워`)이 제목이고
  장소명은 둘째 줄이다. 상세는 장소명(`부산타워`)이 제목이다. 지역도 행 안에서 두 번 나온다(`부산타워 · 중구` · `중구 · 실내`).
  별도 티켓 — 추천 카드 개편(사진 왼쪽 · 설명 오른쪽 · 장소명 제목)과 함께 `PlaceRow` 에서 고친다
- 사진 번호 · 화살표는 `GalleryControls` 가 스크롤 위치를 들고 있다. 사진을 넘겨도 사진 목록은 다시 그려지지 않는다
- **앱 빌드에서 S20 이 빠진다.** APP-CHORE-001 의 `scripts/build-app.sh` 가
  `src/app/[locale]/place` 를 정적 export 에서 제외한다. 앱에서 상세를 열려면
  경로 형태(`?id=` 또는 `generateStaticParams`)를 정해야 한다
- 같은 브랜치에서 fetch 가 `NEXT_PUBLIC_API_BASE` 절대 주소로 바뀐다. 먼저 머지되는 쪽에 맞춘다
- 빈 상태를 `EmptyState` 로 공용화하며 옮긴 `px-[--gutter]` 는 Tailwind 4 에서 `padding-inline: --gutter` 로 나와 무시된다(기존 13곳). 별도 수정
- #20 · #21 · #25 가 main 에 들어온 뒤 main 위로 옮겼다. `page.tsx` 는 #20 의 임시 화면 대신 S20 을 남겼다
