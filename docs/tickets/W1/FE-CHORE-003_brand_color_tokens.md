## Problem

- **현재 동작**: 브랜드 색이 정해지기 전이라 잉크 한 벌(`#111213`)로만 강약을 준다. 보조 텍스트는 배경과 무관하게 `#54565C` 하나다.
- **기대 동작**: 유나 지정 값을 쓰고, 보조 텍스트는 배경에 따라 두 값으로 갈린다.
- **영향 범위**: 토큰을 쓰는 모든 화면. 코드 구조는 바뀌지 않고 값과 클래스만 바뀐다.

## Strategy

### Step 1: 토큰 교체

`globals.css` 한 곳에서 값을 바꾸고 `--sub-on-surface` 를 추가한다. 화면 코드는 건드리지 않는다.

### Step 2: 카드 위 보조 텍스트 적용

카드 · 정보 박스 안에서 `text-sub` 를 쓰는 곳을 새 토큰으로 바꾼다.

```
S02  이렇게 골라드릴게요 카드
S10  유형 카드(내 여행 유형 · 3축 칩)
S03  (카드 없음 — 해당 없음)
S20  정보 박스
```

### Step 3: 검증

`tsc` · `lint` · `build` 와 화면 확인. 화면은 개발 서버 주소와 확인 항목을 정리해 서영님께 부탁한다.

## Implementation Notes

### 지정값에서 벗어난 것 하나

카드 위 보조 텍스트는 유나 지정이 `#21242A` 인데 `#3A3E45` 로 한 단 밝게 넣고, 굵기도
semibold → medium 으로 낮췄다. `#21242A` 는 본문(`#101318`)과 밝기 차가 1.1%p 라
카드 안에서 라벨과 문장이 한 덩어리로 읽혔다. `#3A3E45` 는 밝기 차 4.1%p · 대비 9.7:1.
유나에게 알린다.

### 적용 자리

카드 · 정보 박스 위의 보조 텍스트만 새 토큰을 쓴다 — S02 약속 카드 라벨 · S00 단계 번호 ·
S03 미완성 버튼 글자 · 저장 탭 빈 상태 아이콘. 추천 탭 유형 카드와 S20 "이 곳이 맞는 이유" 는
이미 `text-primary`(잉크)를 써서 바꿀 것이 없었다.

### 검증

`tsc --noEmit` · `eslint` · `npm run build` 통과. 화면은 개발 서버(3150)에서 확인.
