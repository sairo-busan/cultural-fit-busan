## Strategy

**Step 하나 끝날 때마다 멈추고 검토한다.**

1. `AppHeader` 로고 · `TabScreen` 640 기둥 · S10 제목 정리 (`SectionHeader` 삭제 · 조건 줄)
2. `TasteSummary` ㉠ + 캐릭터 에셋 + 스켈레톤 — S10 · 내 정보
3. S10 사진 카드 + 스켈레톤 — ko · en. 사진 넘기기는 PR #31 머지 후 공용 컴포넌트로
4. 저장 탭 작은 행 + 스켈레톤 — 최근 저장순 · 적합도순
5. 검증 · 머지 순서 정리

화면 결과는 392×812 PNG 로 공유한다. 헤드리스 Chrome 은 최소 폭이 500 이라 392 폭 iframe 에 띄워 찍는다.
수치는 목업(`mockup-tokens.css`)이 아니라 코드 토큰 기준이다.
