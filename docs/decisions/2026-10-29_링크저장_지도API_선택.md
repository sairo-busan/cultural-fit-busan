# 링크 저장 · 장소 확정에 쓸 지도 API

날짜: 2026-10-29 / 상태: 확정 (카카오 로컬 API) / 관련: `docs/research/DOCS-002_link_save_feasibility_analysis.md`

## 맥락

링크 저장 실험(`/lab/link-save`)은 링크에서 장소 이름 단서를 뽑아 실제 장소로 확정한다. 확정에 TourAPI `searchKeyword2` 를 쓰면 관광지만 잡히고 식당 · 매장은 빠진다.

| 실측 링크 | 설명란 `📍` 목록 | TourAPI 로 확정 | 빠진 곳 |
|---|---|---|---|
| `youtu.be/izp9Vn3ZNGM` | 5곳 | 2곳 (송정해수욕장 · 해동용궁사) | 부엌우동집 별관 · 롯데 프리미엄 아울렛 동부산점 · 송정 길가 분식과 카페 |

여행 영상에 나오는 곳의 상당수가 식당 · 카페라, 장소 확정은 상호까지 담은 지도 API 가 맡고 TourAPI 는 사이로 카탈로그(적합도 · 상세)와 잇는 데만 쓴다.

## 비교

| | 카카오 로컬 API (키워드 검색) | 구글 Places API (New) Text Search | 구글맵 검색 링크 (`googleMapsUrl`) | TourAPI `searchKeyword2` |
|---|---|---|---|---|
| 찾는 범위 | 국내 상호 · 관광지 대부분 | 국내외 상호 · 관광지 | 검색만 열어 줌 (확정 없음) | 관광공사 등록 관광지 위주 |

| 영문 | 한국어 중심 | 영문 이름 · 주소 제공 | 구글맵 언어 설정을 따름 | 영문 서비스 별도 |

| 저장 | 응답 데이터 별도 저장 불허 (개발자 포럼 FAQ, 약관 대조 필요) [K2] | place_id 만 장기 보관 허용 [G2] | 해당 없음 | 제한 없음 |
| 키 · 준비 | 카카오 디벨로퍼스 REST API 키 | Google Cloud 키 + 결제 계정 | 없음 (이미 S20 에서 사용) | 있음 |

## 결정

**장소 확정은 카카오 로컬 API 키워드 검색으로 한다.** TourAPI 는 사이로 카탈로그 연결에만, 지도 열기는 기존 `googleMapsUrl()` 을 그대로 쓴다.

## 사유

- 실측에서 빠진 식당 · 매장을 잡을 수 있다
- 결제 계정 없이 무료 쿼터로 실험할 수 있다 (구글 Places 는 결제 계정 등록이 먼저)
- 외국인용 지도 열기는 S20 과 같은 구글맵 검색 링크로 유지해, 지도 앱 경험은 바뀌지 않는다

## 남은 확인

- 카카오 로컬 키워드 검색의 일일 무료 쿼터 수치 — 앱 관리 [통계] > [쿼터] 에서 확인
- 저장 제한 [K2] 원문 약관 대조 — 저장하는 것은 사용자가 고른 장소 이름 · 링크이고, 카카오 응답 원본은 저장하지 않는다
- 영문 화면에서 카카오 결과(한국어 이름)를 어떻게 보일지 — 정식 화면 전환 시 결정, 필요하면 구글 Places 로 보강
