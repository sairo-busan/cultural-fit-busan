# 하단 탭을 `추천 · 저장 · 내 정보` 로

2026-09-13 결정. 화면 IA v4.0 의 FLOW 05 를 한 화면으로 묶고, S00 을 탭에서 뺀다.

---

## 결정

```
전   시작 · 추천 · 코스 · 일정       4개 — 코스·일정은 화면이 없어 비활성
후   추천 · 저장 · 내 정보           3개 — 셋 다 갈 이유가 있다
```

`추천` 이 첫 탭이다. 앱을 켜면 바로 추천 목록이 보인다.

---

## 왜 `시작` 을 뺐나

`시작` 탭은 S00 랜딩으로 간다. S00 의 버튼은 둘이다.

```
내 여행 스타일 찾기   →  이미 진단을 마친 사람에게는 의미가 없다
둘러보기             →  지금 보고 있는 화면(S10)이다
```

**진단 후에는 두 버튼 모두 갈 곳이 없다.** 탭은 항상 보이는 자리라, 쓸모없는 목적지가
하나 있으면 나머지 둘의 가치까지 떨어진다.

S00 은 앱 최초 실행 경로로만 남는다. 되돌아가는 길은 `내 정보 → 진단 다시 하기` 다.

## 왜 `내 정보` 인가

IA 에 이미 있는 화면 셋이 이 하나에 들어간다. 새로 발명하는 것이 아니다.

| IA | 이 화면에서 |
|---|---|
| S50 전체 메뉴 | 화면 자체가 대체 |
| S51 언어 | `언어` 줄에서 진입 |
| S52 서비스 소개 · 활용 API | `서비스 소개` · `데이터 출처` 두 줄 |

부수 효과가 셋 있다.

- **헤더가 가벼워진다.** 지금 S10 제목 옆에 `KO` 와 `취향 다시 진단` 이 붙어 있다.
  매번 보일 필요 없는 것들이 제목 자리를 쓰고 있었다.
- **S03 조건으로 돌아갈 길이 생긴다.** 지금은 한 번 지나가면 입구가 취향 카드 안에만 있다.
- **프라이버시를 말할 자리가 생긴다.** "계정 없음 · 기기에만 저장" 은 아키텍처 원칙인데
  화면 어디에도 없었다. 심사의 데이터 활용 항목도 `데이터 출처` 줄로 담긴다.

## 검토했다가 버린 안

| 안 | 버린 이유 |
|---|---|
| `시작 · 추천 · 저장` (현행 유지) | 위 참고 — `시작` 이 진단 후 무의미 |
| `홈 · 추천 · 저장` | `홈` 화면을 새로 만들어야 하는데 IA 에 없고, 담을 내용이 추천 화면 상단(유형·날씨)과 겹친다 |
| `코스` · `일정` 탭 유지 | FLOW 04 화면이 통째로 없다. 비활성 탭은 자리만 차지한다 |

## 남은 것

- `내 정보` 아이콘 — 사람 실루엣 vs 톱니. 계정이 없는 서비스라 "사람" 이 맞는지 확인 필요
- 피그마·슬라이드는 탭 구성이 각각 3개(시작·추천·일정) / 2개(추천·내 여행)로 서로 다르다.
  이 결정은 둘 다 따르지 않는다 — 유나 확인 필요
